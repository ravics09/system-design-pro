# Vertical Scaling

> **In one line:** Making one machine more powerful.

## Overview

Vertical scaling means making one machine more powerful. When the system needs more capacity, you upgrade the server with more CPU, more memory, or faster storage. The application does not change and the architecture does not change. You just get a bigger machine.

## Key Idea

Vertical scaling is simple and works well until it does not. Single machines have a maximum size, and a single machine is a single point of failure.

## Trade-offs & Considerations

- **Simple:** no architectural changes required.
- **Hard ceiling:** machines have a maximum size.
- **No redundancy:** a single machine is a single point of failure — when it goes down, everything goes down with it.

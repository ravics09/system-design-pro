# Object Storage

> **In one line:** Stores large unstructured files as objects identified by a key.

## Overview

Object storage is a system for storing large unstructured files as objects identified by a key. It is infinitely scalable, cheap per gigabyte, and highly durable. Amazon S3 is the most common example.

## Key Idea

Object storage is the right place for images, videos, documents, and backups. It is **not a database** and should not be used like one.

## Trade-offs & Considerations

- Infinitely scalable, cheap, durable.
- Does not support transactions, complex queries, or low-latency random access to small portions of a file.

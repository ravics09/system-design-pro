# Database

> **In one line:** A system for storing, organizing, and retrieving persistent data.

## Overview

A database is a system for storing, organizing, and retrieving data that persists beyond the life of a single request or process. Without a database, any data created during a request disappears when the request ends.

## Key Idea

Databases come in many types optimized for different data shapes and access patterns. The choice of database is one of the **most consequential decisions** in a system design because it is hard to change later and everything else in the system depends on it.

## Trade-offs & Considerations

- Choice is hard to reverse later.
- Type should match the data shape and access pattern.

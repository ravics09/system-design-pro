# Distributed System

> **In one line:** Components running on multiple machines that communicate over a network toward a common goal.

## Overview

A distributed system is a system where components run on multiple machines that communicate over a network to achieve a common goal. Distributed systems are more capable than single-machine systems but introduce a class of problems that do not exist on a single machine: network failures, partial failures, and the challenge of keeping multiple copies of data consistent.

## Key Idea

Understanding distributed systems means accepting that:

- The network is unreliable.
- Clocks on different machines disagree.
- Any component can fail at any time.

Designing for these realities is what distributed systems engineering is about.
